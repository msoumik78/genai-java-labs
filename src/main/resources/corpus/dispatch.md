# After-hours dispatch

A call that reaches the duty phone after 18:00 local time, or on a Sunday, is an after-hours dispatch. The visit fee is ninety-five dollars on top of parts. The fee is quoted before the technician leaves the depot.

Priority code HARBOR waives that night visit fee. The code is printed on the service contract, not on the invoice. Saying the site is near the water does not qualify. The dispatcher must read the code back to the caller and write it on the ticket.

If the caller cancels after the van has left the depot, the ninety-five dollar fee still applies, including when priority code HARBOR waived it, because the waiver covers the visit and not a wasted trip. Storm warnings from the county do not by themselves create a waiver.
